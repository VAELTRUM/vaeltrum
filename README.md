# VAELTRUM — Software Engineering & SaaS Product Development

Official production website for **VAELTRUM**, an independent software engineering and SaaS product development company.

> "Engineering Ideas Into Products."

---

## Brand Positioning & Philosophy

Vaeltrum designs, engineers, and delivers dependable software products built around real-world problems. From early system architecture and product scoping to production deployment and long-term maintenance, our focus is grounded in technical rigor, minimal aesthetics, and authentic credibility.

---

## Architecture & Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite 6 (with manual vendor chunk splitting for Three.js, Framer Motion, and React)
- **Styling**: Tailwind CSS with custom editorial design tokens
- **3D Interactive Core**: Three.js (custom WebGL architectural geometry with mouse inertia, adaptive pixel ratio, and reduced-motion support)
- **Animation**: Framer Motion (subtle scroll reveals, staggered typography entrances)
- **Icons**: Lucide React
- **SEO & Social**: Complete OpenGraph, Twitter Cards, semantic HTML5, and bespoke SVG favicon
